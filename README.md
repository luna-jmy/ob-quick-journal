# Quick Journal

移动优先的日志快速录入插件：点一个按钮、填一个表单，打卡 / 数据 / 小结直接写进
当天日志的对应标题区，全程不进 markdown 编辑模式。周 / 月 / 年汇总视图随时打开即得。

## 依赖

**无需任何其他插件**：解析、统计、界面全部插件内实现。后续版本接入的 Dataview / Tasks /
Templater 均为可选增强（查询块渲染、模板展开），不装也不影响核心功能。

## 安装

### BRAT（测试期推荐）

1. 安装 [BRAT](https://github.com/TfTHacker/obsidian42-brat)；
2. BRAT 设置 → **Add Beta plugin** → 输入 `luna-jmy/ob-quick-journal`；
3. 启用 **Quick Journal**。

### 手动

从 [Releases](https://github.com/luna-jmy/ob-quick-journal/releases) 下载 `main.js`、
`manifest.json`、`styles.css`，放进 `<vault>/.obsidian/plugins/quick-journal/` 后启用。

要求 Obsidian **1.8.7** 或更高版本。

## 用法

- **快速录入**：左侧 ribbon 图标 → 选标题区 → 填表单 → 提交。每个标题区也各有一条命令，
  可绑快捷键或加进移动端工具栏。
- **标题区（设置里自定义）**：以日志标题为单元，四种类型——
  - **打卡**：标题区内每个内联字段一组 ✔️/❌ 开关（不选不写）；
  - **数据**：内联字段填数值（覆盖前会确认）；
  - **文本**：内联字段填一句话小结；
  - **列表**：标题区没有内联字段时逐项追加一行（行模板可配，如 `- [ ] {{value}}` 记任务）。
- **从模板识别**：设置里填模板笔记路径点一下，按标题与内联字段自动重建标题区配置；
  展示名默认取字段键去 emoji，可手改。
- **目标笔记不存在时自动创建**：按标题区配置生成骨架（frontmatter + 标题 + 空值字段行），
  不带查询块与按钮。
- **日志汇总**：命令「打开日志汇总」看周 / 月 / 年的任务完成与新建、打卡率、数值区间
  （按标题区类型出卡）。
- 目录默认 `500 Journal/540 Daily`，可在设置里改；界面语言跟随 Obsidian（中 / 英）。

## 已知限制（原型阶段）

- 复盘（周 / 月 / 年回顾录入与呈现）、查询块区段（dataview / dataviewjs / tasks）、
  趋势图表、上期字段链另行开发，按里程碑推进；
- 未在移动端实机验证的项目见 CHANGELOG 的「未验证」标注；
- 周起始日固定周一（与现有模板的 ISO 周口径一致），设置项后续提供。

## 隐私

纯本地：无网络请求、无遥测、无账号、无外部服务；写入只发生在你明确提交的日志笔记内。
